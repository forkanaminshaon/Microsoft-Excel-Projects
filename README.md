## 🛠️ Tools & Skills Demonstrated

* **Microsoft Excel:** Core application for analysis and visualization.
* **Advanced Formulas:** (e.g., `XLOOKUP`, `SUMIFS`, `INDEX/MATCH`, Dynamic Arrays).
* **Pivot Tables & Slicers:** For interactive data summarization and filtering.
* **Data Visualization:** Using charts, graphs, and conditional formatting to tell a story.
* **Power Query:** (Integrated in Excel) For data extraction, transformation, and loading (ETL).
* **Power Pivot & DAX:** (Integrated in Excel) For building relational data models and advanced measures.

##  How to View These Projects

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/forkanaminshaon/Microsoft-Excel-Projects.git](https://github.com/forkanaminshaon/Microsoft-Excel-Projects.git)
    ```
2.  **Download the Files:**
    Alternatively, you can download individual `.xlsx` files directly from the repository.
3.  **Open the Files:**
    You will need **Microsoft Excel** (2016, 2019, or Microsoft 365) to view these files, as they may use modern features like Power Query or Dynamic Arrays.
